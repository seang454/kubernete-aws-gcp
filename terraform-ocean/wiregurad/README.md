# WireGuard Full-Mesh VPN (GCP + AWS)

This directory contains Ansible automation to configure an encrypted, full-mesh WireGuard VPN (`wg0`) across all 7 nodes (3 GCP Masters + 4 AWS Workers).

            🔒 Encrypted WireGuard Peer-to-Peer Mesh

## How It Works

### 1. Automated Inventory via Terraform
When you run `terraform apply` in `terraform/k8s_infrastructure/live/dev/asia-southeast1/kubespray-k8s`, Terraform automatically creates `wiregurad/inventory/hosts.ini` with:
- Public IPs mapped to `ansible_host` and `wireguard_endpoint`.
- Assigned WireGuard tunnel IPs:
  - `master01` -> `10.0.0.1`
  - `master02` -> `10.0.0.2`
  - `master03` -> `10.0.0.3`
  - `worker01` -> `10.0.0.4`
  - `worker02` -> `10.0.0.5`
  - `worker03` -> `10.0.0.6`
  - `worker04` -> `10.0.0.7`
- Cloud tags (`gcp` / `aws`).

### 2. Common Role (`roles/common`)
- Installs WireGuard dependencies (`wireguard`, `wireguard-tools`, `iptables`, `resolvconf`).
- Enables Linux Kernel IPv4 Forwarding in both live RAM and permanent disk:
  - RAM: `sysctl -w net.ipv4.ip_forward=1`
  - Disk: `/etc/sysctl.d/99-wireguard.conf` & `/etc/sysctl.conf`
- Generates private key (`/etc/wireguard/privatekey`, mode 0600) and public key (`/etc/wireguard/publickey`, mode 0644).
- Reads keys into Ansible facts (`wireguard_public_key`, `wireguard_private_key`) and exports public key copies to controller `./keys/`.

### 3. WireGuard Role (`roles/wireguard`)
- Deploys `/etc/wireguard/wg0.conf` configured as a **Full Mesh**:
  - `[Interface]`: Current node's address (`10.0.0.x/24`), `ListenPort = 51820`, `PrivateKey`.
  - `[Peer]`: 6 peer blocks (one for every other node in the cluster) with `PublicKey`, `Endpoint`, `AllowedIPs = 10.0.0.y/32`, and `PersistentKeepalive = 25` (maintains active NAT hole-punching across GCP & AWS).
- Starts & enables `systemd` service:
  ```bash
  sudo systemctl enable --now wg-quick@wg0
  ```

## Usage

### Deploy WireGuard Mesh to all 7 machines:
```bash
cd terraform/wiregurad
./run-wireguard.sh
# or directly:
ansible-playbook -i inventory/hosts.ini site.yml
```

### Verify Handshake and Peer Connectivity:
```bash
cd terraform/wiregurad
./run-wireguard.sh verify
# or directly:
ansible-playbook -i inventory/hosts.ini verify.yml
```

## Manual Verification Commands (on any node)

1. **Check WireGuard status and handshake timestamps**:
   ```bash
   sudo wg show
   ```
   *Verify that `latest handshake: X seconds ago` appears for each peer.*

2. **Ping cross-cloud peer**:
   - From AWS Worker (`10.0.0.4`):
     ```bash
     ping -c 4 10.0.0.1
     ```
   - From GCP Master (`10.0.0.1`):
     ```bash
     ping -c 4 10.0.0.4
     ```

## Bonus: Adding a Windows Server Node

If you ever add a Windows Server node to the mesh:
1. Download and install WireGuard from [wireguard.com/install](https://www.wireguard.com/install/).
2. Open WireGuard → Click **Add Tunnel** → **Add empty tunnel...**.
3. Configure:
   ```ini
   [Interface]
   PrivateKey = <AUTOMATICALLY_GENERATED_PRIVATE_KEY>
   Address = 10.0.0.8/24
   ListenPort = 51820

   [Peer]
   PublicKey = <GCP_OR_AWS_NODE_PUBLIC_KEY>
   Endpoint = <NODE_PUBLIC_IP>:51820
   AllowedIPs = 10.0.0.0/24
   PersistentKeepalive = 25
   ```
4. Click **Save** → **Activate**.
